# 설치 — Claude에게 맡기기

**강의가 시작될 때 이것부터 걸어 둔다.** 15~25분 걸리는데 그동안 강의를 들으면 된다.

받은 `setup` 폴더에서 터미널을 열고 `claude`를 실행한 뒤,
아래 상자 안을 그대로 붙여넣는다.
운영체제(Windows · macOS · Linux)에 맞춰 Claude가 알아서 처리한다.

---

```
같은 폴더에 있는 SETUP.md를 읽고, 거기 적힌 대로 실습 환경을 만들어줘.
내 운영체제에 맞는 쪽을 골라서 진행하면 돼.

주의할 점:
- SETUP.md에 적힌 순서와 버전을 그대로 지켜줘. 임의로 바꾸지 마.
- 특히 --no-deps를 빼면 안 돼. 이유는 SETUP.md에 적혀 있어.
- 나는 프로그래밍을 모르니까, 내가 직접 해야 하는 일이 생기면
  (예: 파이썬 설치, git 설치) 무엇을 어디서 받아야 하는지 알려줘.

마지막에 00_check.py를 실행하고, [FAIL]이 있으면 원인을 찾아 고친 다음
다시 돌려줘. 모두 [OK]가 될 때까지 반복해줘.
("TDC 데이터 다운로드"만 실패하는 건 괜찮아 — 넘어가도 돼.)

다 끝나면 이것들을 알려줘:
- 설치된 python / chemprop / admet_ai / PyTDC 버전
- 다음에 실습할 때 가상환경을 다시 켜는 명령 (내 OS 기준)
- 00_check.py의 최종 출력
```

---

## 끝나면 이 두 줄을 확인한다

```
[OK]   admet_ai (2.0.1이어야 함)        2.0.1
[OK]   ADMET-AI 값 대조                aspirin VDss -2.70 · 열 104개 — 자료와 일치
```

**여기가 `[FAIL]`이면 버전이 잘못 깔린 것이다.** Claude에게 다시 시킨다.

## 막히면

```
지금 무엇 때문에 막혔는지, 내가 직접 해야 할 게 있는지 알려줘.
```

그래도 안 되면 `SETUP.md`를 직접 보면서 손으로 해도 된다.
손을 든 김에 옆 사람이 먼저 끝났으면 어떻게 했는지 물어봐도 좋다.

> **쉬는 시간에 한 번만 확인한다.** `[FAIL]`이 있으면 그때 알려 주면
> 실습 시작 전에 고칠 수 있다. 설치가 도는 동안에는 신경 쓰지 않아도 된다.
