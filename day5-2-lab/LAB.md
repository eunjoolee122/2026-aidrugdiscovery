## 예측할 항목 — MDR1-MDCK 유출비

**MDCK**는 개 신장 상피세포주다. 단층막을 이루면 장 상피와 비슷한 «막»이 되어
화합물이 얼마나 통과하는지 잴 수 있다. 여기에 **사람 MDR1 유전자(P-당단백질)를 넣은 것**이
MDR1-MDCK다. P-gp는 세포 안에 들어온 약물을 다시 밖으로 퍼내는 펌프다.

```
유출비 ER = Papp(B→A) / Papp(A→B)      퍼내는 속도 ÷ 들어오는 속도
```

| ER | 뜻 |
|---|---|
| ≈ 1 | 펌프가 관여하지 않는다 |
| > 2 | P-gp가 퍼내고 있다 — 흔히 이 선에서 「기질」로 판정한다 |
| ≫ 10 | 강하게 퍼낸다 — 경구 흡수와 뇌 투과가 크게 제한된다 |

뇌를 노리는 약이 P-gp 기질이면 혈뇌장벽에서 계속 퍼내져 효과가 나지 않는다.
리드 최적화에서 **구조를 조금씩 바꿔 ER을 낮추는 일**이 자주 벌어진다.

**데이터** — `er_dataset.csv` · 2,642개 · 열은 `smiles`와 `log_er` 둘뿐.
ER이 아니라 log ER을 쓰는 이유는 비율이라 분포가 심하게 쏠리기 때문이다
(중앙값 1.42인데 최대 531). log를 취하면 −1.16 ~ 2.73으로 펴진다.

# 2부 — 이 점수를 비교할 수 있는가 (25분)

## ③ 점수를 모은다

**칠판에 각자의 R²를 적는다.**

미리 네 번 돌려 둔 결과다. 여러분 것도 이 근처일 것이다.

| 실행 | 분할 방식 | 모델 수 | **R²** | 시간 |
|---|---|---|---|---|
| A | scaffold | 3개 앙상블 | **0.519** | 16분 |
| B | scaffold | 5개 앙상블 | **0.508** | 25분 |
| C | **random** | 3개 앙상블 | **0.473** | 28분 |
| D | scaffold | 3 replicate | **0.529** | 17분 |

네 번 모두 **시키지도 않았는데** scaffold 분할을 고르고(C만 random), 앙상블을 하고,
Random Forest 베이스라인과 비교까지 했다.

> **숫자가 비슷하다. 그러면 「우리 모델은 다 비슷하다」고 말해도 되는가?**

## ④ 시험지를 비교한다

각자 Claude에게 시킨다.

```
내 모델이 평가에 쓴 test set의 SMILES 목록을 뽑아줘.
그리고 옆 사람 목록과 몇 개나 겹치는지 세어줘.
```

네 실행의 시험지를 실제로 비교한 결과다.

| | 겹치는 화합물 |
|---|---|
| A ∩ B | 24 / 264 (**9%**) |
| A ∩ C | 22 / 264 (8%) |
| B ∩ D | 37 / 264 (14%) |

**시험지가 90% 다르다.** 그런데 점수는 비슷하게 나왔다.

### 더 심각한 것

| | |
|---|---|
| A의 시험 문제 중 **D가 이미 공부한 것** | 219 / 264 = **83%** |
| C의 시험 문제 중 A가 공부한 것 | 222 / 265 = **84%** |
| B의 시험 문제 중 C가 공부한 것 | 216 / 264 = **82%** |

**내 시험 문제의 80%를 옆 사람은 교과서에서 이미 봤다.**

> **여기가 오늘의 핵심이다.**
> 점수가 비슷하다고 해서 같은 것을 잰 것이 아니다.
> 각자 다른 시험지로 봤고, 그 시험지는 남에게는 교과서였다.
> **이 숫자들은 나란히 놓을 수 없다.**

숫자가 크게 갈렸다면 오히려 알아챘을 것이다. **비슷하게 나온 것이 함정이다.**

# 3부 — 공정하게 다시 잰다 (35분)

## ⑤ 공통 시험지로 다시 평가한다

`er_train.csv` (2,114개) 와 `er_test.csv` (528개) 를 나눠준다.

- 골격(scaffold) 기준으로 나눠서 **겹치는 골격이 0개**다
- 학습 쪽과 시험 쪽의 log_er 분포가 거의 같다 (평균 0.399 vs 0.395)
- **모두가 같은 528개로 평가하므로 이제 점수를 나란히 놓을 수 있다**

```
er_train.csv 로만 학습하고 er_test.csv 로 평가해줘.
train 안에서 검증셋을 떼는 건 괜찮지만, er_test.csv 는 학습에 절대 쓰지 마.
시드를 1, 2, 3 으로 세 번 돌려서 평균과 범위를 내줘.
```

### 참고값 (같은 조건으로 미리 돌려 둔 것)

| 방법 | R² 평균 | 범위 |
|---|---|---|
| 처음부터 학습 | **0.416** | 0.406 ~ 0.431 |

**1부에서 0.52가 나왔는데 여기서는 0.42다.** 모델이 나빠진 게 아니라
**시험지가 달라졌을 뿐이다.** 어느 쪽이 «진짜» 성능인지는 아무도 모른다 —
다만 이제 **서로 비교할 수는 있다.**

시드에 따른 흔들림은 **0.025**로 작다. 1부처럼 시험지까지 매번 달랐다면
이 흔들림이 훨씬 컸을 것이다.

## ⑥ 이미 학습된 모델을 가져다 쓴다

**아무도 시도하지 않은 것이 하나 있다.** ADMET-AI라는 공개 도구에는
이미 학습된 분자 인코더가 들어 있다. 항목은 다르지만
「분자를 숫자로 바꾸는 부분」은 재활용할 수 있다.

```
admet_ai 패키지의 resources/models/admet_regression/model_0.pt 를 불러와서
message passing 부분만 가져다가 er_train.csv 로 파인튜닝해줘.
예측층은 새로 만들고, 평가는 똑같이 er_test.csv 로 해줘. 시드 1,2,3.

그리고 message passing 을 얼려서(requires_grad=False) 예측층만 학습하는 것도
따로 해서 세 방법을 비교해줘.
```

### 참고값

| 방법 | R² 평균 | 범위 | MAE |
|---|---|---|---|
| **처음부터 학습** | **0.416** | 0.406 ~ 0.431 | 0.386 |
| encoder 파인튜닝 | 0.400 | 0.379 ~ 0.414 | 0.404 |
| encoder 고정 | 0.302 | 0.294 ~ 0.306 | 0.448 |

**가져다 쓴다고 좋아지지 않았다.** 처음부터 학습한 것이 오히려 조금 높다.
차이(0.016)가 시드 흔들림(0.025)보다 작으니 **둘은 구별되지 않는다**고 보는 것이 맞다.

**encoder를 얼린 것만은 확실히 낮다**(0.302, 세 시드 모두). 대신 학습 시간이 짧다.

> 데이터가 2,114개나 있으면 처음부터 배워도 충분하다는 뜻이다.
> 공개 모델을 가져다 쓰는 것이 유리한 상황은 따로 있다.

## ⑦ 성능을 실제로 올려 본다

ADMET-AI에는 인코더가 **5개** 들어 있다(`model_0.pt` ~ `model_4.pt`).
하나만 쓰지 말고 다 써 보자.

```
두 가지를 비교해줘. 둘 다 er_train.csv 로 학습하고 er_test.csv 로 평가해줘.

  (가) model_0.pt ~ model_4.pt 다섯 개를 각각 초기값으로 써서 다섯 번 파인튜닝
  (나) 사전학습 없이 초기값만 다르게 다섯 번 학습

각각 개별 다섯 개의 R²와, 다섯 예측을 평균했을 때의 R²를 내줘.
그리고 화합물마다 다섯 예측의 표준편차도 구해서,
편차가 큰 화합물이 실제로 더 많이 틀리는지 확인해줘.
```

### 참고값

| | 개별 다섯 평균 | **다섯을 평균(앙상블)** | 이득 |
|---|---|---|---|
| (가) ADMET-AI 체크포인트 | 0.380 ± 0.022 | 0.441 | **+0.060** |
| (나) 무작위 초기값 | 0.418 ± 0.020 | **0.460** | **+0.042** |

**둘 다 앙상블이 확실히 이득이다.** 다섯이 서로 다른 실수를 하기 때문에
평균이 그 실수를 상쇄한다. 개별 최고보다 평균한 쪽이 높다.

**그리고 ⑥의 결론이 여기서도 유지된다** — 사전학습을 가져다 쓴 쪽(0.441)이
그냥 만든 쪽(0.460)보다 낮다. 이 데이터에서는 가져다 쓸 이유가 없다.

### 얼마나 못 믿을지도 알 수 있다

| 다섯 예측의 편차 | 화합물 수 | **실제 오차(MAE)** |
|---|---|---|
| 하위 25% (잘 맞음) | 132 | **0.324** |
| 25~50% | 132 | 0.342 |
| 50~75% | 132 | 0.425 |
| 상위 25% (많이 갈림) | 132 | **0.468** |

편차가 큰 화합물이 실제로 더 많이 틀린다.

> **다만 한계가 있다.** 편차와 실제 오차의 순위상관은 **0.17~0.19**로 약하다.
> 서로 다른 세 번의 실행에서 모두 같은 값이 나왔으니 우연이 아니다.
> **구간으로 나눠 보는 것**은 되지만, 화합물 하나를 짚어
> 「편차가 크니 이건 틀렸다」고 말할 수는 없다.
> 제대로 된 불확실성이 필요하면 chemprop의 evidential·MVE 같은 별도 기능을 써야 한다.

## ⑧ 보고서를 다시 쓴다

1부에서 쓴 `report.md`를 다시 연다.

```
report.md 를 다시 써줘. 오늘 알게 된 것을 반영해줘.

  - 처음 점수는 내가 만든 시험지로 잰 것이라 남과 비교할 수 없었다는 것
  - 공통 시험지로 재니 0.52가 아니라 0.42였다는 것
  - 공개 모델을 가져다 써도 나아지지 않았다는 것 (차이가 흔들림보다 작다)
  - 다섯을 앙상블하면 0.38에서 0.44로 오른다는 것
  - 예측 편차로 못 믿을 화합물을 구간별로 표시할 수 있다는 것

처음 보고서에서 무엇이 성급했는지도 한 문단으로 적어줘.
```

**첫 보고서도 거짓말은 아니었다.** 표가 있었고 숫자도 맞았다.
**다만 그 숫자가 무엇과 비교될 수 있는지를 말하지 않았을 뿐이다.**
