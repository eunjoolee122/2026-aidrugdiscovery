## 예측할 항목 — MDR1-MDCK 유출비

**MDCK**는 개 신장 상피세포주다. 단층막을 이루면 장 상피와 비슷한 «막»이 되어
화합물이 얼마나 통과하는지 잴 수 있다. 여기에 **사람 MDR1 유전자(P-당단백질)를 넣은 것**이
MDR1-MDCK다. P-gp는 세포 안에 들어온 약물을 다시 밖으로 퍼내는 펌프다.

```
유출비 ER = Papp(B→A) / Papp(A→B)      퍼내는 속도 ÷ 들어오는 속도
```

| ER | 뜻 |
|---|---|
| ≈ 1 | 펌프가 관여하지 않는다 |
| > 2 | P-gp가 퍼내고 있다 — 흔히 이 선에서 「기질」로 판정한다 |
| ≫ 10 | 강하게 퍼낸다 — 경구 흡수와 뇌 투과가 크게 제한된다 |

뇌를 노리는 약이 P-gp 기질이면 혈뇌장벽에서 계속 퍼내져 효과가 나지 않는다.
리드 최적화에서 **구조를 조금씩 바꿔 ER을 낮추는 일**이 자주 벌어진다.

**데이터** — `er_dataset.csv` · 2,642개 · 열은 `smiles`와 `log_er` 둘뿐.
ER이 아니라 log ER을 쓰는 이유는 비율이라 분포가 심하게 쏠리기 때문이다
(중앙값 1.42인데 최대 531). log를 취하면 −1.16 ~ 2.73으로 펴진다.

# 2부 — 이 점수를 비교할 수 있는가 (25분)

## ③ 점수를 모은다

**칠판에 각자의 R²를 적는다.**

미리 네 번 돌려 둔 결과다. 여러분 것도 이 근처일 것이다.

| 실행 | 분할 방식 | 모델 수 | **R²** | 시간 |
|---|---|---|---|---|
| A | scaffold | 3개 앙상블 | **0.519** | 16분 |
| B | scaffold | 5개 앙상블 | **0.508** | 25분 |
| C | **random** | 3개 앙상블 | **0.473** | 28분 |
| D | scaffold | 3 replicate | **0.529** | 17분 |

네 번 모두 **시키지도 않았는데** scaffold 분할을 고르고(C만 random), 앙상블을 하고,
Random Forest 베이스라인과 비교까지 했다.

> **숫자가 비슷하다. 그러면 「우리 모델은 다 비슷하다」고 말해도 되는가?**

## ④ 시험지를 비교한다

**먼저 파일을 받는다.** 터미널에서 한 줄이면 된다.

```
git pull
```

`data/part2/` 가 생긴다. 옆 사람 파일을 주고받을 필요는 없다 —
**같은 프롬프트로 미리 돌려 둔 두 사람의 시험지**가 여기 들어 있다.

| 파일 | 내용 |
|---|---|
| `other_run_1_test.csv` · `other_run_1_train.csv` | 한 사람의 시험지와 교과서 |
| `other_run_2_test.csv` · `other_run_2_train.csv` | 다른 사람의 것 |

**Claude에게 이렇게 시킨다.**

```
내 모델이 평가에 쓴 test set의 SMILES 목록을 뽑아줘.
그다음 data/part2/other_run_1_test.csv, other_run_2_test.csv 와 비교해서
  1. 내 시험지와 몇 개나 겹치는지
  2. 내 시험 문제 중 몇 개가 part2/other_run_1_train.csv, other_run_2_train.csv 에
     (= 그 사람들의 학습 데이터에) 들어 있는지
를 세어줘. SMILES는 RDKit으로 정규화해서 비교해줘.
```

**비교는 Claude가 한다. 한 줄씩 눈으로 볼 일은 없다.**

### 미리 돌려 둔 두 사람은 이랬다

| | |
|---|---|
| 두 사람의 시험지가 겹치는 화합물 | **24 / 264 = 9%** |
| 1번의 시험 문제 중 **2번이 이미 공부한 것** | **185 / 264 = 70%** |
| 2번의 시험 문제 중 1번이 공부한 것 | **214 / 264 = 81%** |

**시험지가 90% 다르다.** 그런데 점수는 0.47~0.53으로 비슷하게 나왔다.

**그리고 내 시험 문제의 70~80%를 남은 교과서에서 이미 봤다.**

> **여기가 오늘의 핵심이다.**
> 점수가 비슷하다고 해서 같은 것을 잰 것이 아니다.
> 각자 다른 시험지로 봤고, 그 시험지는 남에게는 교과서였다.
> **이 숫자들은 나란히 놓을 수 없다.**

숫자가 크게 갈렸다면 오히려 알아챘을 것이다. **비슷하게 나온 것이 함정이다.**

## ⑤ 자유롭게 올려 본다 (30분)

```

무엇을 왜 시도했는지, 결과가 어땠는지 기록해줘.
잘 안 된 시도도 빼지 말고 적어줘.
```

### 무엇을 해볼지 막히면

Claude에게 물어본다. 「이 데이터에서 성능을 올릴 만한 방법을 몇 가지 제안해줘.」

물어보기 전에 스스로 생각해 볼 것들이다.

- 분자를 **숫자로 바꾸는 방식**을 바꿔 본다면?
- **모델 종류**를 바꿔 본다면? 신경망이 아니어도 되는가?
- 데이터에 **손볼 곳**은 없는가? (2부에서 본 것들)
- 여러 모델을 **합치면** 어떤가?

> **잘 안 되는 것도 결과다.** 「해봤는데 나아지지 않았다」가
> 「무엇을 했는지 모르겠다」보다 훨씬 낫다.
